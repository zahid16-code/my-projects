## Economic Data Analysis
- **Description:** In this project, I analyzed economic data to identify trends, patterns, and important insights. The dataset includes various economic indicators, and the goal was to understand the relationships between different variables.
- **Technologies Used:** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook
- **Key Insights:**  
   - Correlation between economic factors  
   - Trends over the years  
   - Visualizations and hypothesis testing
- **How to Run:**
  1. Clone this repository:  
     ```bash
     git clone https://github.com/zahid16-code/my-projects.git
     ```
  2. Navigate to the project directory:
     ```bash
     cd economic_data_analysis
     ```
  3. Install dependencies:
     ```bash
     pip install -r requirements.txt
     ```
  4. Run the Jupyter Notebook:
     ```bash
     jupyter notebook economic_data_analysis.ipynb
     ```

## Bank Marketing Campaign - Logistic Regression
- **Description:** This project uses logistic regression to predict whether a customer will subscribe to a bank's term deposit based on various demographic and behavioral features.
- **Technologies Used:** Python, Scikit-learn, Pandas, Matplotlib, Seaborn
- **Key Steps:**
  - Preprocessing of data (encoding categorical variables, handling missing data)
  - Model training using Logistic Regression
  - Evaluation using classification report and confusion matrix
- **How to Run:**
  1. Clone this repository:  
     ```bash
     git clone https://github.com/zahid16-code/my-projects.git
     ```
  2. Navigate to the project directory:
     ```bash
     cd bank_logistic_regression
     ```
  3. Install dependencies:
     ```bash
     pip install -r requirements.txt
     ```
  4. Run the Python script:
     ```bash
     python bank_logistic_regression.py
     ```
